## 步骤 1：创建 HttpMethod 枚举类

**文件位置**：`src/main/java/cc/jfire/boot/forward/path/HttpMethod.java`（新建文件）

**改动内容**：

```java
package cc.jfire.boot.forward.path;

/**
 * HTTP 请求方法枚举
 */
public enum HttpMethod
{
    GET,
    POST,
    PUT,
    DELETE,
    PATCH,
    HEAD,
    OPTIONS,
    /**
     * 匹配所有 HTTP 方法（默认值）
     */
    ALL;

    /**
     * 判断当前枚举值是否匹配指定的请求方法
     *
     * @param requestMethod 请求的 HTTP 方法字符串（如 "GET"、"POST"）
     * @return 如果匹配返回 true，否则返回 false
     */
    public boolean matches(String requestMethod)
    {
        if (this == ALL)
        {
            return true;
        }
        return this.name().equalsIgnoreCase(requestMethod);
    }
}
```

## 步骤 5：修改 PathRequestForwardProcessor 的路由匹配逻辑

**文件位置**：`src/main/java/cc/jfire/boot/forward/path/PathRequestForwardProcessor.java`

### 5.1 修改 handleHttpRequest 方法

将第 39-70 行的 `handleHttpRequest` 方法修改为：

```java
private void handleHttpRequest(HttpRequest data, ReadProcessorNode next)
{
    String path = "";
    try (HttpRequestExtend requestExtend = HttpRequestExtend.from(data, next.pipeline()))
    {
        path = requestExtend.getPath();
        String requestMethod = requestExtend.getMethod();
        List<PathRequest> pathRequests = requestMap.get(path);
        boolean pathExists = pathRequests != null && !pathRequests.isEmpty();

        if (pathRequests != null)
        {
            for (PathRequest pathRequest : pathRequests)
            {
                if (pathRequest.matchesMethod(requestMethod))
                {
                    Object value = pathRequest.invoke(requestExtend);
                    if (value != null)
                    {
                        next.pipeline().fireWrite(value);
                    }
                    return;
                }
            }
        }

        // 精确路径未匹配，尝试 RESTful 路由
        Map<String, Object> paramMap = requestExtend.getNotNullParamMap();
        // 由于 restfulMatch.match(...) 可能会向 paramMap 写入路径参数，这里先快照一份原始参数（通常包含 URL query 参数）
        Map<String, Object> originalParamMap = new HashMap<>(paramMap);
        boolean restfulPathExists = false;
        for (PathRequest restfulRequest : restfulRequests)
        {
            // 每次匹配前先恢复 paramMap，避免上一次匹配写入的路径参数污染后续匹配
            paramMap.clear();
            paramMap.putAll(originalParamMap);
            if (restfulRequest.getRestfulMatch().match(path, paramMap))
            {
                restfulPathExists = true;
                if (restfulRequest.matchesMethod(requestMethod))
                {
                    Object value = restfulRequest.invoke(requestExtend);
                    if (value != null)
                    {
                        next.pipeline().fireWrite(value);
                    }
                    return;
                }
            }
        }

        // 路径存在但方法不匹配，返回 405
        if (pathExists || restfulPathExists)
        {
            HttpResponse response = new HttpResponse();
            response.getHead().setStatusCode(405);
            response.getHead().setReasonPhrase("Method Not Allowed");
            response.setBodyText("Method Not Allowed");
            next.pipeline().fireWrite(response);
            return;
        }

        // 路径不存在，传递给下一个处理器（404）
        next.fireRead(requestExtend);
    }
    catch (Throwable e)
    {
        log.error("请求出现异常,当前请求路径:{}", path, e);
        HttpResponse response = new HttpResponse();
        response.setBodyText("error:" + e.toString());
        next.pipeline().fireWrite(response);
    }
}
```

**补充说明**：
- 上述代码新增了 `HashMap` 的使用，因此需要在 `PathRequestForwardProcessor.java` 顶部补充 import：`java.util.HashMap`。

### 6.2 修改 parseFromApplication 方法

```java
private static Map<String, PathRequest> parseFromApplication(ApplicationContext context)
{
    context.makeAvailable();
    return context.getAllBeanRegisterInfos().stream()//
                  .flatMap(beanRegisterInfo -> Arrays.stream(beanRegisterInfo.getType().getDeclaredMethods()))//
                  .filter(method -> method.isAnnotationPresent(Path.class))//
                  .map(method -> new PathRequest(method, context.getBeanRegisterInfo(method.getDeclaringClass()).get().getBean()))//
                  .collect(Collectors.toMap(PathRequest::getPath, Function.identity()));
}
```

修改为：

```java
private static Map<String, List<PathRequest>> parseFromApplication(ApplicationContext context)
{
    context.makeAvailable();
    return context.getAllBeanRegisterInfos().stream()//
                  .flatMap(beanRegisterInfo -> Arrays.stream(beanRegisterInfo.getType().getDeclaredMethods()))//
                  .filter(method -> method.isAnnotationPresent(Path.class))//
                  .map(method -> new PathRequest(method, context.getBeanRegisterInfo(method.getDeclaringClass()).get().getBean()))//
                  .collect(Collectors.groupingBy(PathRequest::getPath));
}
```

**改动说明**：
- 返回类型从 `Map<String, PathRequest>` 改为 `Map<String, List<PathRequest>>`
- 收集器从 `Collectors.toMap()` 改为 `Collectors.groupingBy()`，自动将相同路径的 PathRequest 分组到列表中
